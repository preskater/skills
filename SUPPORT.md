# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/preskater/skills/discussions) for questions, ideas, and "how do I" help. Discussions keep issues focused on actionable work.

## Bugs and feature requests

Open an issue with the matching template:

- **Bug report** for a skill, the installer, or the validator
- **Feature request** for a change to an existing skill or bundle
- **New skill proposal** for a skill that does not exist yet

Include the skill name, the harness, the version, and the prompt or command that triggered the problem.

## Security

Report vulnerabilities through [private advisories](https://github.com/preskater/skills/security/advisories/new). Never open a public issue for a security problem.

## What to expect

This is a community project maintained on a best-effort basis. There is no SLA, but we aim to triage new issues within a week.

## Before opening an issue

- Search existing issues and discussions.
- Run `node scripts/validate.mjs` if you changed the repository.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) if you plan to send a change.
